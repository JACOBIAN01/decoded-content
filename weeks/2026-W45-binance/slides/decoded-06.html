The off switch, in code
// A stablecoin transfer, simplified
function transfer(from, to, amount) {
  if (blocklist.has(from)) throw "frozen";
  balance[from] -= amount;
  balance[to] += amount;
}
// Bitcoin has no blocklist line.
// Only: is the signature valid?
One line decides whether stolen money can be stopped.
